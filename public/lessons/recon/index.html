Setup Digital Ocean (do)#

Security Tip: Using a Custom Scope token adheres to the principle of least privilege while still being able to run ax.

Step 1: Access Digital Ocean API Settings#

  1. Sign up using my referral link for free credits.
  2. Navigate to the API Tokens & Keys panel.
  3. Click Generate New Token and select Custom Scope.

Step 2: Configure Token Scopes#

Grant these 9 permissions to prevent unauthorized errors:

Resource Type Permissions
account read
actions read
droplet create, read, update, delete, admin
image create, read, update, delete
regions read
sizes read
snapshot create, read, delete
ssh_key create, read, update, delete
vpc read

Once the installation finishes, you’re ready to start your first fleet and launch a scan.
