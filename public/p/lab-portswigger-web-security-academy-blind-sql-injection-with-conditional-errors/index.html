Lab: Portswigger Web Security Academy Blind SQL Injection with Conditional Errors

Jun 19, 2024
3 minute read

# Description

This lab contains a blind SQL injection vulnerability. The application uses a tracking cookie for analytics, and performs an SQL query containing the value of the submitted cookie.

The results of the SQL query are not returned, and the application does not respond any differently based on whether the query returns any rows. If the SQL query causes an error, then the application returns a custom error message.

The database contains a different table called users, with columns called username and password. You need to exploit the blind SQL injectionvulnerability to find out the password of the administrator user.

# Skill Learned

  • SQL injection in a cookie parameter using sqlmap

# Solution

# Finding the vulnerability

To solve the lab, log in as the administrator user.

Adding a single qoute (') causes an error. Errors are usually a good sign when testing for SQLi. I use sqlmap to dump the administrator’s password in the next section.
